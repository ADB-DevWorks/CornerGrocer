# CornerGrocer

## Overview
Program to read a daily sales inventory file, create a count of items and rewrite to a dat file.
The program gives a user interface for viewing different reports. 
There is a search feature to type an item and retrieve the sales count of the item.
The user can also view a item list with counts given or as a histogram.
I has been writen to be maintainable and adaptable by being mmodular and
having a seperation of concerns, such as the UI is seperate from the logic and the models.
